# Meu Portfólio Profissional | Julia - Software Engineer

Este é o repositório do meu portfólio pessoal, projetado para apresentar minha trajetória na **Engenharia de Software**, minhas competências técnicas e minhas certificações em **Cloud Computing**.

---

## O que você encontrará aqui?

O portfólio foi estruturado para fornecer uma visão 360º das minhas capacidades técnicas e acadêmicas:

1. **Core Competencies:** Uma seção de leitura rápida com as tecnologias que domino (C#, .NET, AWS, React).
2. **Featured Projects:** Demonstração prática do meu trabalho, incluindo o projeto **Valoreco** e sistemas de leitura de dados.
3. **Experience (LabMov):** Detalhamento das minhas responsabilidades como estagiária de engenharia de software.
4. **Cloud Showcase:** Espaço dedicado à minha certificação **AWS Certified Cloud Practitioner**, com links de validação de badges.
5. **Education:** Meu percurso acadêmico em Engenharia de Software e Análise de Sistemas.

---

## Tecnologias Utilizadas

Para manter o portfólio leve, performático e com foco em **Clean Code**, utilizei:

- **HTML5 Semântico:** Para garantir acessibilidade e melhor indexação (SEO).
- **CSS3 Moderno:** Utilizando Flexbox e Grid para um design responsivo e elegante.
- **JavaScript:** Para manipulação dinâmica de elementos e interatividade.
- **Inter Font Family:** Focando em legibilidade e tipografia moderna.

---

## Decisões de Engenharia

Ao construir este portfólio, tomei decisões baseadas em boas práticas de mercado:

- **Mobile First:** O layout foi pensado para ser consumido tanto em desktops quanto em dispositivos móveis.
- **Escalabilidade:** A estrutura do HTML permite adicionar novos projetos e certificações de forma modular.
- **Performance:** Otimização de carregamento de recursos para garantir que o recrutador tenha uma experiência fluida.
